# Prompty – příroda (zvěř, ptáci, hmyz, kůň, počasí, roční období)

Základ je hotový (viz `PROJECT_LOG.md`, záznam „Příroda …“, a `ZVIRATA.md`).
Každý soubor je samostatné zadání pro **novou session** Claude Code. Napiš např.:
*„Přečti a proveď `prompts/priroda/02_pocasi_a_hratelnost.md`.“*

| # | Soubor | Obsah |
|---|---|---|
| 01 | `01_ladeni_modelu_a_animaci.md` | vzhled a animace zvířat podle připomínek, IK nohou na svahu, lehání, skoky, výkon |
| 02 | `02_pocasi_a_hratelnost.md` | přilnavost aut na mokru / sněhu / náledí, stěrače, promoknutí a prochladnutí, mlha |
| 03 | `03_rocni_obdobi_zemedelstvi_svatky.md` | pole podle sezóny, květy, sezónní předměty, svátky a události v obci |
| 04 | `04_zver_a_hrac.md` | srážka se zvěří a její hlášení, myslivec a krmelec, stopy ve sněhu, stáj a péče o koně |
| 05 | `05_priroda_v_multiplayeru.md` | synchronizace kalendáře, počasí, zvěře a koní (až po hlavních úkolech 03 a 06) |

Pořadí 01–04 je volné (01 doporučeno první), 05 až po síťovém základu. Každý úkol: agent hru ani testy
nespouští (jen na výslovný pokyn), na konci checklist ručních testů pro uživatele.
